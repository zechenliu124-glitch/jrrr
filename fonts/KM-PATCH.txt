KM Pixel 12 — modification notice

km-pixel-12.woff2 in this folder is a Modified Version (SIL Open Font License 1.1, see OFL-KMPixel12.txt) of
Fusion Pixel Font 12px Proportional zh_hans, release 2026.08.11, by TakWolf (with glyphs from Ark Pixel Font,
Cubic 11 and Galmuri; their licenses are bundled in OFL-KMPixel12.txt).

Changes made for 骑士魔法 (Knight Magic):
1. Subset to the characters the game displays plus GB2312 level 1, family renamed to "KM Pixel 12", the
   half-width middle dot, narrowed space and synthesized spaces described in tools/subset.py (REMAP, space_px).
2. KM patch 1 (tools/patch_font.py): the digit 0 is drawn without the diagonal slash (a plain 5x9 oval).
3. KM patch 2 (tools/patch_font.py): the em dash U+2014 is a full-width bar, 12 font pixels wide at the
   height of 一 (y 400-500 of 1200 units, left bearing 0, advance 1200). Upstream drew it with the same 11-pixel
   bitmap as 一 (U+4E00), so the Chinese dash 「——」 read as 「一一」; now two dashes join into one unbroken line.
   The name table version string reads "Version 2026.08.11; KM patch 1: plain zero; KM patch 2: joined em dash".

The file is generated by `python3 -I tools/subset.py` (which applies both patches) and is byte-for-byte reproducible
from the same code; `python3 -I tools/subset.py --check` lists displayed characters the file does not cover.

The 2026 upstream license has no Reserved Font Name; the renamed family is used anyway.
