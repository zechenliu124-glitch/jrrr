两个文件的画面完全一样，只是动画“谁来触发”不同。

## 怎么放映

1. 用 PowerPoint（2013 及以上）或 WPS 演示打开，按 **F5** 从头放映。
2. **单击鼠标 / 按空格 / 翻页笔** 翻页。不会自动翻页，没有背景音乐。
3. 每页的**完整台词、建议用时、动画顺序、点击时机**都写在幻灯片**备注**里，排练时打开“演示者视图”就能看到。
4. 字幕已经做成图片，**不用安装任何字体**，换电脑放映也不会走样。

## 小提示

* 第 1 页的标题放在天空里（小蜗牛从左下角爬进来，标题放上面才不挡住它）；其余每页的字都在画面下方，不挡主角。
* 一键版每页的动画时间是按“正常语速”排的（见备注里的“约第 N 秒”），每页最后都留了几秒空当；小朋友语速差别大时，建议用逐句点击版。
* 如果动画还没放完就单击：PowerPoint 的规矩是第一下先让动画直接放完，再单击一次才翻页。
* 第 3、6 页编辑时能看到两只小蜗牛，这是为了让小蜗牛分两段慢慢爬（放映时只会看到一只），请不要删除。
* 最后一页讲完鞠躬后不用再点（再点会出现黑屏“放映结束”），按 Esc 退出放映即可。
* `preview/` 里有每页的画面图和动画预览视频 `preview/anim/all.mp4`（按一键版的时间自动播放，用来提前看效果）。

## 想改字或改动画？（给会用电脑的家长）

所有台词、屏幕大字和动画时间都在 `tools/story.py` 里，画面是 `art/` 里的 SVG 水彩插画。改完后运行：

```bash
npm install playwright        # 只需第一次（用来把 SVG 画成图片）
pip install python-pptx pillow lxml
python3 tools/build.py        # 重新生成两个 .pptx 和 preview/ 预览图
python3 tools/simulate.py all # 可选：生成动画预览视频 preview/anim/all.mp4
```
