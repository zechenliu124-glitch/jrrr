# 骑士魔法

3D 割草游戏：选一位骑士，跳、滑、变强到离谱，打通三关。

在线玩：https://zechenliu124-glitch.github.io/jrrr/

## 装到 iPad 主屏幕

1. 用 Safari 打开上面的网址。
2. 点「分享」→「添加到主屏幕」→「添加」。
3. 第一次从主屏幕图标打开时要联网。看到「已存到本机，没网也能玩」以后，断网也能玩。
4. 以后有新版本，联网打开就会自动更新，不用重装。

## 叠罗汉

布娃娃叠塔小游戏：小人挂在云朵上左右晃，点一下把他放下去，一个踩一个，看能叠多高。

- 只有一个文件 `dieluohan.html`，下载后双击用浏览器打开就能玩，不用联网。
- 电脑：点鼠标或按空格；手机：点屏幕。按 M 或右上角按钮开关声音。
- 发布到 GitHub Pages 后的地址：https://zechenliu124-glitch.github.io/jrrr/dieluohan.html
