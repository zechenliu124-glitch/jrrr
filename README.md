# 骑士魔法

3D 割草游戏：选一位骑士，跳、滑、变强到离谱，打通三关。

在线玩：https://zechenliu124-glitch.github.io/jrrr/

## 装到 iPad 主屏幕

1. 用 Safari 打开上面的网址。
2. 点「分享」→「添加到主屏幕」→「添加」。
3. 第一次从主屏幕图标打开时要联网。看到「已存到本机，没网也能玩」以后，断网也能玩。
4. 以后有新版本，联网打开就会自动更新，不用重装。
